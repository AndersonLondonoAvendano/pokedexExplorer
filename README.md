# PokéDex Explorer

App móvil hecha con **React Native + Expo (SDK 57)** que consume la [PokéAPI](https://pokeapi.co). Muestra una lista de Pokémon con scroll infinito, permite buscarlos por nombre o número y abre su ficha con imagen, tipos y estadísticas.

Entrega del *Taller Consumo de API con React Native y Expo — PokéDex*.

**Integrantes:** _PENDIENTE: nombres del grupo_

---

## Cómo ejecutar

```bash
npm install                 # instala las dependencias del package.json
npx expo start              # escanea el QR con Expo Go, o presiona a (Android) / i (iOS)
```

Requisitos: Node 20 o superior y Expo Go compatible con el SDK 57.
